# 阶段 0：从描述 / Markdown 生成手绘 SVG（references/from-description.md）

当输入**不是 SVG**，而是文字描述或 Markdown 文档（产品说明、脚本、创意草稿）时，
先执行本阶段：把内容结构化 → 选择布局模板 → 生成符合 `handdrawn-style.md` 的手绘 SVG。
产出仍是一份标准手绘 SVG，无缝进入阶段 1–4。

## 输入类型识别

| 输入 | 示例 | 策略 |
|---|---|---|
| 一句话描述 | "把创作流程画成四步流水线" | 直接按布局模板展开 |
| Markdown 文档 | 45 秒视频脚本、产品说明.md | 解析标题层级/列表/表格 → 提取模块 |
| 已有 SVG + 补充描述 | 深色版 SVG + 想加的模块 | 阶段 1 直接手绘化，仅用描述补缺失块 |

## 1. 内容结构化（解析 → 元素分组）

从 MD 中提取五类元素，对应手绘骨架：

1. **Header 信息**：作品名（logo 固定用 mosu_logo.png）、副标题（INNOVATION 0N · …）、右上便签（一句话卖点）。
2. **大标题**：cap（一句说明）+ headline（核心概念）+ 橙色下划线 + sub（展开句）。
3. **模块卡片**：每个 `## 小节` / 列表项 = 一张卡片，卡片内再分标题行 + 若干内容行。
   规则：卡片数量 ≤ 6；每卡内容 ≤ 5 行；编号用圆形徽章（1/2/3…）。
4. **关系/箭头**：列表顺序、`→` 符号、表格流向 = 箭头。主流程箭头 1–4 条；
   `循环`/`回退`/`重试` 词 → 虚线反馈回路。
5. **收尾**：价值徽章（一句话）→ 落地箭头 → 「真实 APP 界面落地」标签 → 底部标语（中文 + 英文缩写）。

## 2. 布局模板选择

按模块数量与关系选骨架（坐标直接套用，内容替换）：

| 模板 | 适用 | 参考样板 |
|---|---|---|
| **三列并列**（中列宽） | 3 个大模块 + 中枢 | 创新一：中枢居中，左右各一卡 |
| **横向流水线**（4 卡 + 大中枢） | 步骤链式流程 | 创新二：表达→AI中枢→理解→计划→工具→确认/产出 |
| **四步流水线 + 闭环** | 有循环/重试 | 创新三：解析→双重锁定→分轨→校验 + 闭环回路 |
| **单列纵向** | 少模块长文案 | 可按需新增 |

坐标骨架（1920×1080）：
- Header：logo (111,80)、标题 x=158、便签 translate(1504 51)；主体整体 `translate(0 -42)` 或 `-78` 上移。
- 卡片行：y≈244–552；卡片 x 按数量均分（如 4 卡：80/464/1130/1510，宽 340/622/336/340）。
- 箭头 y≈399 水平线（`M.. 399C.. 391 .. 391 .. 399` + 歪头 `l-12-9M.. l-12 9`）。
- 落地：价值徽章 y≈585、下箭头 y≈632–658、落地标签 translate(828 670)、底部标语 y≈991/1035。

## 3. 生成步骤

1. 读入 MD，按上文结构化提取五类元素（输出一份《元素分组清单》供用户确认）。
2. 选布局模板，把内容填入坐标骨架。
3. 按 `handdrawn-style.md` 的令牌上色/描边/字体/旋转/虚线/手绘箭头。
4. logo 用 `scripts/embed_logo.py` 内嵌 base64。
5. 校验：`python scripts/verify_sync.py <svg> <html> <token>... --xml`（XML 合法 + 关键文本完整）。

## 验收清单

- [ ] 元素分组清单与用户描述一致（模块/箭头/标语无遗漏）
- [ ] 布局模板与模块数量匹配，卡片无重叠、无超边框
- [ ] 输出为符合手绘规范的自包含 SVG（logo 内嵌、XML 合法）

## 示例（MD → 元素分组）

```markdown
# 多角色配音
1. 台词解析：文本 → 发音脚本
2. 双重锁定：谁在说 + 怎么说
3. 分轨生成：对白 TTS + 拟声词音效
4. 自动校验：不达标自动重试（循环）
```
→ 模块 4 张卡 + 3 主线箭头 + 1 闭环回路 → 套「四步流水线 + 闭环」模板
→ 即 `墨塑_创新三_多角色智能配音闭环` 的布局来源。
