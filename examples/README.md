## 阶段 3：细节调整案例（踩坑修复记录）

| 症状 | 修复 |
|---|---|
| 元素堆左上角/错位 | CSS `transform` 覆盖 SVG `transform` → keyframes 只用独立 `translate` |
| 紫色细框提前露出 | `stroke-dasharray` 从 1600/5200 加大到 5400（≥ 最大框周长） |
| 胶囊文字被不透明紫块遮挡 | `opacity=".12"` 被 CSS 动画覆盖 → 改 `fill-opacity=".12"` |
| 「一致性中枢」文字跑右下角 | `<g translate>` 内放绝对坐标文字 → 去 g 用绝对坐标直排 |
| 技术底座黑底黑字 | CSS 类优先级高于内联 `fill="#FFF"` → 新增白色文字类 |
| 按钮碰边框 | 按钮组 `translate` 上移（如 540→520），断言 底 < 内虚线底 |
| 文字超出标签框 | 加宽 rect 或缩字号（15→13），断言 右缘 < 框右缘 |

## 复用方法

新项目（如创新三、新架构图）只需：
1. 提供深色/科技风 SVG 源 → 按 `references/handdrawn-style.md` 手绘化；
2. 生成动画 HTML → 按 `references/animation-html.md`（动画基元 + 串行时序 + 箭头动画 + 踩坑清单）；
3. 用户反馈细节调整 → 按阶段 3 表格对症修；
4. `scripts/export_4k.ps1` 一键导出 4K MP4 → 按 `references/export-4k.md` 验证。
