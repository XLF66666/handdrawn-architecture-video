## 从描述 / MD 生成手绘 SVG（阶段 0 样例）

输入是文字描述而非 SVG 时，按 `references/from-description.md` 走阶段 0。
下面是一个真实映射示例（MD 输入 → 元素分组 → 布局模板）：

```markdown
# 多角色配音（输入 MD）
1. 台词解析：把自然文本转换为发音脚本
2. 双重锁定：锁定「谁在说」+「怎么说」
3. 分轨生成：对白进入角色 TTS 声轨，拟声词进入音效声轨
4. 自动校验：检查声纹/韵律/分流，不达标自动重试（循环）
```

| 映射步骤 | 结果 |
|---|---|
| 内容结构化 | 4 个模块卡片（带编号徽章）+ 3 条主线箭头 + 1 条闭环虚线 + 价值徽章 + 落地标签 + 标语 |
| 布局模板 | 「四步流水线 + 闭环」→ 创新三布局：解析(80,244) → 双重锁定(464,228) → 分轨(1130,244) → 校验(1510,244)，箭头 y≈399 |
| 产出 | `墨塑_创新三_多角色智能配音闭环_手绘精修版.svg`（logo 已内嵌 base64） |

提示：模块 ≤6、每卡内容 ≤5 行、`→`/列表顺序生成箭头、出现「循环/重试/回退」生成虚线反馈回路。

### 阶段 3：细节调整案例（踩坑修复）

| 症状 | 修复 |
|---|---|
| 元素堆左上角/错位 | CSS `transform` 覆盖 SVG `transform` → keyframes 只用独立 `translate` |
| 紫色细框提前露出 | `stroke-dasharray` 加大到 ≥ 最大框周长（5400） |
| 胶囊文字被不透明块遮挡 | `opacity=".12"` 被 CSS 覆盖 → 改 `fill-opacity=".12"` |
| 文字跑出画面 | `<g translate>` 内禁止绝对坐标文字 → 去 g 绝对直排 |
| 黑底黑字看不见 | CSS 类优先级高于内联 `fill` → 新增白字类 |
| 按钮碰边框 | 按钮组 `translate` 上移，断言 底 < 内虚线底 |
| 文字超出标签框 | 加宽 rect 或缩字号，断言 右缘 < 框右缘 |
